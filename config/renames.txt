# Identifier renames, applied by scripts/apply_renames.py as whole-word replacements across src/, include/,
# symbol_addrs.txt, config/*.txt and overlays/*.sym. Re-run the script after merging other branches: it is
# idempotent, and on main it must be a no-op (every old name is gone).
#
# Format:
#   OldName NewName      one pair per line; `#` starts a comment. Several old spellings of one address
#                        (off_/dword_/stru_ aliases) may map to the same new name. Chains (A B, then B C) work.
#   [UNIT UNIT ...]      section header: the pairs below it, up to the next header, only apply to the files
#                        of these units. A unit is an overlay (its overlays/<name>.sym name: GAME, BATTLE,
#                        COMBBTL, ...; its files are src/overlays/<name>.c, <name>_<n>.c, <name>.h and
#                        overlays/<name>.sym) or EXE (every other file: src/*.c/h, symbol_addrs.txt, config/).
#   [ALL]                the pairs below apply to every file (the default at the top of the file).
#
# Overlays loaded at the same address (TITLE, COMBAT, TSTCOMPO, GAME at 0x800A05A0; COMB* at 0x800A4088;
# BATTLE, MENU, MAP, LOAD, ... at 0x800B66C0) reuse addresses for different things, so a pair whose name
# has an overlay-area address (0x800A05A0 and up) must be in a [UNIT ...] section (the script refuses it in
# [ALL]). Name the overlay that defines the symbol plus every unit that refers to it by that name: EXE when
# the game code or symbol_addrs.txt uses it, overlays loaded above it (BATTLE, EVENTFNC, MENU, MAP call
# GAME). The same old name may appear in several sections as long as their units do not overlap.
